## ✨ About The Project

**Clouthes Store** is a full-stack e-commerce platform engineered with real-world architecture and scalability in mind.

> 💡 Built as a **production-grade SaaS-ready system**, not just a demo.

---

## 🧠 Project Story

This project started as a learning journey into full-stack development
and evolved into a **complete e-commerce system** simulating real business scenarios:

* Handling real payments 💳
* Managing orders & users 📦
* Building scalable backend architecture 🧱
* Designing modern frontend experiences 🎨

> 🎯 The goal: Build something that could actually be used in production.

## 🧠 Architecture

```text
Frontend (Next.js)
        ↓
API (ASP.NET Core)
        ↓
Application (CQRS)
        ↓
Domain (Business Logic)
        ↓
Infrastructure (EF Core + SQL + Redis)
```

---

## 🏗️ Tech Stack

### Backend ⚙️

## 🚀 Getting Started

```bash
git clone https://github.com/Saifahmed3993/Clouthes-Store-by-Saif
```

### Backend

```bash
cd src/ClouthesShop.API
dotnet run
```

### Frontend

```bash
cd Clouthes WEB
npm install
npm run dev
```
